# Регрессионные проверки trace_viewer

Запускай приложение из корня практикума по [README.md](../README.md#запуск). Для сравнения до и после используй тот же каталог исходных XLS и параметры запуска. Запиши запросы, статусы, `Content-Type` и полные тела ответов до правки. После переноса повтори затронутые запросы. При структурной правке сравни значения, наличие полей, порядок строк, этапов и других элементов массивов, адреса источников и сообщения ошибок. При полном рефакторинге выполни проверки API и браузера целиком.

## Проверки API

Все запросы используют метод GET. Примеры рассчитаны на текущие выгрузки. В успешных ответах и ответах 400 и 404 ожидается `application/json; charset=utf-8`.

| Запрос | Ожидаемый результат |
| --- | --- |
| `/api/months` | 200. Список идентификаторов и названий месячных листов. |
| `/api/orders` и `/api/order-coverage` без параметров и с `month=2022-03` | 200. В текущих выгрузках март идёт первым, поэтому запросы без параметра дают март. У отчёта `stage_count=7`. Сравни номера и порядок строк, значения покрытия, расхождений и неоднозначности. Повтори оба метода для остальных месяцев из `/api/months`. |
| `/api/trace?month=2022-03&row=145`, затем те же запросы для 148 и 184 | 200. По умолчанию используются весь месяц, поиск без ограничения смены и автоматический выбор версии. Сверь эталонные строки из следующего раздела и ссылки на источники. Для марта проверь также запрос с опущенным `month`. |
| `/api/trace?month=2022-03&row=145&recipe=all&shift=2` | 200. Проверка выбора всех версий и явной смены. Повтори с `shift=1` и `recipe=auto`. |
| `/api/trace?month=2022-03&row=145&from=2022-03-28&to=2022-03-28&shift=2` с дополнительным `recipe=<id>` | 200. Возьми и закодируй идентификатор из `versions` ответа для заказа 145. Сверь выбранную версию и строки на включённых границах периода. |
| `/api/trace?month=2022-03&row=184&from=2022-03-01&to=2022-03-01` | 200. У дозирования `outside_period=true`, среди соседних записей видна строка 332 от 3 марта. |
| `/api/trace?month=2022-03&row=145&from=2022-03-28&to=2022-04-03`, затем `/api/source?file=3&month=2022-04&row=8` | 200 в обоих запросах. Среди записей подачи есть строка 8 листа «апрель 2022». Запрос источника открывает апрельский лист. |
| `/api/source?file=4&month=2022-03&row=3637`, `/api/source?file=6&month=2022-03&row=655`, `/api/source?file=8&month=2022-03&row=197` | 200. Сверь фактические имена книг, листы, номера строк и поля. |
| `/api/trace?month=2022-03&row=145&from=1901-01-01&to=1901-01-01` | 200. Производственные этапы пусты. Справочные сведения и исходная строка заказа могут присутствовать. |
| `/api/trace?month=2022-03&row=145&shift=3` | 400. Ошибка «Укажите смену 1 или 2.». |
| `/api/source?file=8&month=2022-03&row=0` | 404. Ошибка «Запрошенная строка или лист не найдены.». |

## Контрольные заказы в марте 2022

Открой лист «март 2022», выбери заказ по номеру строки, оставь весь месяц, все смены и автоматический выбор шихты. Эти же строки и значения сверяй в ответах API.

- **145.** На переходе к прессовке за 28 марта, смена 2, расходится код распоряжения. В дозировании строка 3637 содержит `3181/59`, марка массы `153356`. В прессовке строка 655 содержит `3171/59`, марка массы по справочнику `153357`. Открой обе ссылки и сверь книгу, лист и строку. На переходе к садке есть неоднозначность по строкам прессовки 655 и 656 с 120 и 370 годными штуками.
- **148.** На этапе «Печи» в строке 197 рядом показаны дата входа 4 марта и дата выхода 5 марта 2022 года. Ссылка открывает ту же исходную строку.
- **184.** При поиске за весь месяц видны дозирование от 3 марта, строка 332, и прессовка от 1 марта, строка 2.

## Действия в браузере

Для затронутой части интерфейса повтори обычные действия и сверь результаты с исходным поведением.

- Переключи месячный лист, найди заказ по строке или коду, проверь режимы «Все заказы», «Лучшие маршруты» и «Без расхождений». Измени смену и версию шихты, открой этап и пояснения к переходу.
- На этапе с длинной таблицей проверь сортировку в обе стороны, включая строки за кнопкой «Показать ещё». Пустые значения остаются в конце.
- Открой исходную строку с клавиатуры, закрой диалог и проверь возврат фокуса. Измени ширину панели стрелками и клавишами Home и End. Проверь сворачивание и раскрытие панели.
- Проверь пустой результат и отображение ошибки запроса, если менялась соответствующая обработка. При правках вкладок проверь также «Шихту» и «Проценты и простои».

В результате проверки запиши использованные команды, запросы и входы, результаты сравнения и причины пропуска проверок.
